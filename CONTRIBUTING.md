# Contributing

_(Skeleton placeholder authored in WP0; the full contributor documentation is
written by the documentation work package.)_

Planned contents (from the approved spec):

- Core coding standards review; text domain `default`; abilities written core-landing-ready.
- Canonical schema single-source rule: PRs that change a canonical ability's schema to work around a consumer incompatibility are rejected — fix the consumer instead.
- Every new ability requires a linked core trac/GitHub ticket.
- Permission negative and positive tests required on every gate path.
- Rename protocol: names are adopted once and never aliased.
